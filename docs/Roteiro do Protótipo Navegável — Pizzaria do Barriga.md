# Roteiro do Protótipo Navegável — Pizzaria do Barriga

**Link do protótipo:** [url do Figma/Penpot, com acesso de visualização liberado]

https://www.figma.com/design/hd8egMUs65MPhKonVAZqMm/Pizzaria-do-Barriga?node-id=0-1&t=CICJG11ynvcxe2Zv-1

| Tela | Perfil | História relacionada (E2) | O que a tela mostra/permite |
|---|---|---|---|
| Login/Cadastro | Ambos | #1 | Formulário de credenciais dos funcionários / clientes. Permite o acesso do usuário |
| Cadastro de Produtos | Funcionário | #2, #3 | Permite que o funcionário realize o cadastro de produtos para os clientes e separe-os de acordo com a sua categoria |
| Cardápio de produtos | Cliente | #4 | Permite que o cliente visualize os produtos e entenda quais produtos a pizzaria possui sem precisar do atendente |
| Colocar produtos no carrinho | Cliente | #5 | Permite que o usuário visualize o carrinho com os produtos antes de pedir |
| Formulário de contato | Cliente | #6 | Permite que o usuário informe os dados de contato e entrega |
| Acompanhamento dos pedidos | Ambos | #7, #8 | Permite que o funcionário visualize em tempo real os pedidos recebidos e aceite-os para adentrar a fila e permite que o cliente visualize o status|
